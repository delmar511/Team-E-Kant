# 하이브리드가 항상 나은가 — RRF 가중치 쓸기

- 일시: 2026-11-25
- 담당: 서종찬
- 벡터: `nlpai-lab/KURE-v1` (1024차원)
- 평가셋: `eval/eval-dev.json` 8문항
- 재현: `python src/retrieve.py --config B --w-bm25 <w> --eval eval/eval-dev.json`

## 질문

구성 B(BM25 + 벡터, RRF)는 발제가 제시한 구성이다. 하지만 임베딩 모델을
`KURE-v1` 으로 바꾸자 **벡터 단독(구성 A)이 8/8** 이 됐다.
그러면 BM25 를 섞는 것이 여전히 이득인가?

## 결과

| w_bm25 | Hit@5 | MRR |
| --- | --- | --- |
| 1.0 (동등 가중치 = 원래 RRF) | 7/8 | 0.557 |
| 0.5 | 7/8 | 0.641 |
| 0.3 | 7/8 | 0.620 |
| 0.1 | 8/8 | 0.646 |
| **0 (= 구성 A, 벡터 단독)** | **8/8** | **0.792** |

참고: BM25 단독은 4/8, MRR 0.453.

**어떤 가중치에서도 구성 A 를 넘지 못한다.**
BM25 를 섞는 것 자체가 dev 에서는 순손해다.

## 왜 동등 가중치가 해로운가

RRF 점수는 `w / (k + rank)` 다. `k=60` 이므로 1위는 `1/61`, 2위는 `1/62` 로
**순위 간 차이가 1.6% 밖에 안 된다.** 반면 검색기 간 품질 차이는
MRR 0.792 대 0.453 으로 크다.

동등 가중치에서는 BM25 1·2위가 벡터 1위와 사실상 동점이 된다.
정렬이 안정 정렬이고 BM25 목록을 먼저 넘기므로, 동점일 때 BM25 가 앞선다.
**결과적으로 4/8 짜리 검색기가 상위 두 자리를 거저 가져간다.**

실제로 w=1.0 에서 정답 순위가 1위 -> 3위로 밀린 문항이 4개 있다
(DEV-001, 004, 005, 008). 셋 다 A 에서는 1위였다.

## 그러나 BM25 를 버릴 수는 없다

DEV-006 만 따로 보면 이야기가 다르다.
`학사과정(D-2-2)과 석사과정(D-2-3) 유학생의 시간제취업 허용 시간은?`

| 구성 | 정답 순위 |
| --- | --- |
| BM25 단독 | **1위** |
| 구성 A (KURE 단독) | 3위 |
| 구성 B (w=1.0) | **1위** |
| 구성 B (w=0.1) | 3위 |

**코드를 정확히 구분해야 하는 질문에서는 BM25 가 고유한 기여를 한다.**
보호 토큰이 `D-2-2` 를 한 덩어리로 지키기 때문이다.
벡터는 OpenAI 든 KURE 든 이 문항에서 1위를 못 냈다.

가중치를 낮추면 이 기여도 같이 사라진다. 맞바꿈 관계다.

## 결론 — 조건부다

**dev 기준으로는 구성 A(KURE 단독)가 최선이다.** 그러나 그대로 확정하지 않는다.

- dev 8문항 중 코드 구분이 필요한 문항은 DEV-006 하나뿐이다.
- test 20문항은 `direct` 10 + `confusable` 4 로, 코드를 정확히 가려야 하는
  문항 비율이 dev 보다 높을 가능성이 있다.
- 그 비율이 높아지면 BM25 의 기여가 손실을 넘어설 수 있다.

**test 평가셋이 채워지면 w_bm25 를 0 / 0.1 / 0.5 / 1.0 으로 다시 쓸어본다.**
dev 에서 정한 값을 test 에 그대로 쓰지 않는다.

## 설계에 대해 배운 것

발제는 "A: Vector 단독, B: BM25+Vector(RRF)" 를 제시하면서
B 가 A 보다 나을 것을 암묵적으로 가정한다. 우리 데이터에서는 그렇지 않았다.

**하이브리드가 이득인지는 두 검색기의 품질 격차에 달려 있다.**
격차가 작으면 서로 보완하고, 크면 약한 쪽이 강한 쪽을 끌어내린다.
같은 코드가 임베딩 모델 하나를 바꾸자 결론이 반대가 된 것이 그 증거다.

| 벡터 모델 | 구성 A | 구성 B (w=1.0) | BM25 의 역할 |
| --- | --- | --- | --- |
| OpenAI 3-large | 7/8 | **8/8** | 도움 |
| KURE-v1 | **8/8** | 7/8 | 방해 |

## 표본 주의

8문항이다. MRR 0.641(w=0.5)과 0.620(w=0.3)의 역전은 노이즈로 본다.
믿을 수 있는 건 **w 가 커질수록 나빠진다는 방향**과
**A 와 B 의 격차(0.792 대 0.557)가 크다는 것** 두 가지뿐이다.
