## 경위

`eval-test.json` 의 `chunk_id` 는 `link_evidence.py` 의 버그로 생긴 값이었다
(상세: `2026-11-26_eval-test-gold-bug.md`). 박태환이 근거 32건에 `quote` 를 채워
`eval-test-quoted.json` 으로 다시 연결했다.

```
quote 모드 연결 결과 (근거 32건)
  ok               25
  spans_multiple    2
  partial           5
  not_found         0
```

원본 정답지와 비교하면 **32건 중 25건(78%)이 달랐다.** 원본이 그만큼 틀려 있었다.

`--mode facts` 로 내가 보정했던 12건은 **11건이 확정 정답과 일치**했다.
불일치 1건은 TEST-004 evidence[1]. 검색기를 전혀 쓰지 않고 `expected_facts` 만으로
뽑은 값이므로, 순환 논증이 아니었다는 뒷받침이 된다.

## 측정

```

정답지 확정         구성 A   15/17   MRR 0.774

```

구성 A 는 17건 중 15건 적중, 그중 **12건이 1위**.

현재 `w_bm25 = 1.0` 이라 BM25 와 벡터가 동등한 발언권을 갖는다.
RRF 는 점수를 버리고 순위만 쓰므로 **검색기의 품질 차이도 함께 버린다.**
KURE-v1 이 이 도메인에서 BM25 보다 확실히 강한데, 동등 가중이면 BM25 의
엉뚱한 상위 후보가 벡터의 1위를 밀어낸다.

→ 다음 단계: **dev 에서** `--w-bm25` 를 조정한다. test 로 조정하면 과적합이다.
