# 검색을 처음부터 다시 만들어 보기

본 코드(`src/`)는 청크가 1,646개다. 뭐가 일어나는지 볼 수가 없다.
여기서는 **청크 8개**로 같은 것을 처음부터 만든다. 전부 눈으로 확인할 수 있는 크기다.

데이터: `learn/mini_chunks.jsonl` — 실제 매뉴얼에서 뽑은 8개

| # | 문서 | 내용 |
| --- | --- | --- |
| 1 | D-2 | 시간제취업 > 나. 대상 |
| 2 | D-2 | 시간제취업 > 다. 허용범위 (시간 제한) |
| 3 | D-2 | 시간제취업 > 마. 신청서류 |
| 4 | D-2 | 자격 해당자 및 활동범위 |
| 5 | D-2 | 체류자격 변경허가 > 제출서류 |
| 6 | D-4 | 체류자격외 활동 |
| 7 | E-7 | 근무처 변경·추가 > 제출서류 |
| 8 | A-1 | 외교 자격 해당자 (무관한 방해꾼) |

## 연습에 쓸 질문 셋

이 셋이 각각 다른 문제를 드러낸다.

| 질문 | 정답 | 무엇을 드러내나 |
| --- | --- | --- |
| Q1 `유학생이 알바하려면 뭘 내야 해?` | 3번 | **말이 다르다**. 매뉴얼엔 '알바' 가 없고 '시간제취업' 이라고 적혀 있다 |
| Q2 `D-2 체류자격 변경 제출서류` | 5번 | **흔한 말**. '제출서류' 는 5·7번에 다 있다 |
| Q3 `시간제취업 대상` | 1번 | **말이 같다**. 어휘 검색이 가장 잘하는 경우 |

## 순서

| 단계 | 파일 | 무엇을 알게 되나 |
| --- | --- | --- |
| 1 | `step01_naive.py` | 가장 단순한 검색이 왜 안 되는가 |
| 2 | `step02_tokenize.py` | 조사 때문에 생기는 문제, 비자 코드 보호 |
| 3 | `step03_bm25.py` | BM25 점수를 손으로 계산해 본다 |
| 4 | `step04_embedding.py` | 뜻을 숫자로 바꾼다는 게 무슨 말인가 |
| 5 | `step05_compare.py` | 두 방식이 서로 다른 걸 찾는 이유 |
| 6 | `step06_rrf.py` | 합치기. 그리고 오늘 본 함정 |
| 7 | `step07_eval.py` | Hit@5 로는 왜 모자란가 |

각 단계는 30줄 안쪽이다. **돌려보고 출력을 읽는 게 핵심**이지 코드를 외우는 게 아니다.

## 규칙

- 한 번에 한 단계만 한다
- 돌리기 **전에** 결과를 예상해 본다. 틀리면 그게 배울 지점이다
- 출력이 이상하면 그게 정상이다. 이상한 걸 보려고 만든 연습장이다
