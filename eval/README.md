# 평가셋

| 파일 | 문항 | 구성 | 용도 |
|---|---|---|---|
| `dev.json` | 10 | 답변 가능 8 + 근거 없음 2 | 개발·튜닝 전용 |
| `test.json` | 20 | 직접검색 10 + 표현변형·유사조건 7 + 근거 없음 3 | **최종 평가 전용** |

## 내 담당 범위

평가셋 작성은 문제·평가 설계 담당 몫이지만, **`gold_chunks` 채우기는 내 작업**이다.
색인을 만들기 전에는 청크 ID가 없으므로 비워둔 채 시작한다.

1. 청킹·색인 생성 (`idx-v1`)
2. 각 문항의 `gold_location`(조항)에 해당하는 청크를 찾아 `gold_chunks` 기입
3. `frozen_at` 기록하고 커밋 ← **2일차 오후 데드라인**
4. 청킹을 바꾸면 2~3을 다시 수행

## 금지

- `test.json` 20문항을 3일차까지 열지 않는다
- 이 파일들을 검색 색인에 넣지 않는다 (정답표가 섞이면 평가가 무의미)

## 분모

- Hit@5 / 정답 충족 / 근거 적합 → **17**
- 근거 없음 대응 → **3**
