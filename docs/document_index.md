# 문서 대장 (document_index.md)

> 평가표 **3번**(출처 확인)과 **10번**(데이터 이용)의 증빙.
> 발제 요건: 문서 ID, 제목, 출처, 이용 조건, 버전 또는 수집 시점, 원문 위치를 기록한다.

## 조달 방식

`[팀 회의에서 확정 — 실제 법령 수집 / 제도 기반 자체 작성]`

| 방식 | 저작권 | 비고 |
|---|---|---|
| 법령 본문 (법·시행령·시행규칙) | 보호 대상 아님 (저작권법 제7조 1호) | 원문 커밋 가능 |
| 국가·지자체 고시·공고 | 보호 대상 아님 (제7조 2호) | 원문 커밋 가능 |
| 하이코리아 안내·해설 | 공공저작물 | 이용 조건 별도 확인 |
| 팀 자체 작성 | 자체 제작 | 참고용 안내임을 명시 |

## 기준 시점

`[기입]` 기준으로 고정한다. **이후 법령이 개정돼도 재수집하지 않는다** — 중간에 바뀌면 평가셋의 근거 매핑이 전부 깨진다.

## 범위

- 비자 유형 **5~6개**로 한정한다. 출입국관리법 전체를 넣으면 30문항 정답 매핑이 끝나지 않는다.
- 답변 가능한 서로 다른 업무 질문 25개를 커버하면 충분하다. 파일 개수는 성과가 아니다.

## 제외 범위 (평가표 10번)

- 개인 신청자 정보는 색인에 넣지 않는다. 문서는 규정과 고시만 담는다.
- "이 사람 승인해도 되나요?" 같은 **판정 요청은 범위 밖**이다. 이 시스템은 절차 안내만 한다.
- 참고용 안내이며 실제 심사 판단을 대체하지 않음을 명시한다.
